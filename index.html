Skrypt Minecraft Lab

Zobacz przykład czystego kodu napisanego w pluginie Skript.

xenon_core.sk
Skript 2.8+ • Minecraft 1.20+

command /xenoncore:

trigger:

open chest inventory with 3 rows named "&b&lXENONCORE USŁUGI" to player

set slot 13 of player's inventory to nether star named "&a&lDołącz na Discord"

send "&8[&bXenonCore&8] &7otwarto menu usług!" to player


on inventory click:

if name of player's current inventory is "&b&lXENONCORE USŁUGI":

cancel event

if clicked slot is 13:

send "&bSprawdzaj nasz Discord w celu rozpoczęcia projektu!" to player

close player's inventory
